Die Zuordnung, Bildgrößen, Alt-Texte und Beschreibungen stehen in `src/lib/current-projects.ts`. Bei abweichenden Originalgrößen dort Breite und Höhe aktualisieren. Kleine Vorschaubilder laden verzögert; beim Vergrößern auf derselben Seite wird eine größere Bildvariante geladen, die den vollständigen Bildinhalt bewahrt.

Die Bilder ergänzen die Projekttexte als kleine, leicht gedrehte Papierkärtchen. Adeltuner zeigt vier überlappende Kärtchen. Klick, Escape und Schließen-Button öffnen bzw. schließen die Vergrößerung. Im Entwicklungsmodus nach Änderungen die Seite neu laden; für die veröffentlichte Website neu bauen und deployen.
